# タスク

## データ

| 項目               | 内容                                                          |
| ------------------ | ------------------------------------------------------------- |
| `id`               | UUID。サーバーが採番                                          |
| `userId`           | 所有者。タスクは所有者だけが見られる                          |
| `title`            | 前後の空白を除いて 1〜200 文字                                |
| `dueAt`            | 締め切り。任意。UTC の ISO 8601 で保存                        |
| `completedAt`      | 完了日時。未完了は `null`                                     |
| `reminderQueuedAt` | リマインドをキューに積んだ日時 ([reminders.md](reminders.md)) |
| `createdAt`        | 作成日時                                                      |

## 入力のルール

実装: `apps/web/src/lib/task-input.ts`

- タイトルは前後の空白を取り除き、1〜200 文字でなければ 400 (`タイトルは1〜200文字で入力してください。`)。
- 締め切りは日時として解釈できなければ 400 (`締め切りの日時が正しくありません。`)。空文字・未指定は「締め切りなし」(`null`)。タイムゾーン付きの値は UTC に直して保存する。
- 完了にすると完了日時が現在時刻になり、未完了に戻すと `null` に戻る。

## 並び順

1. 未完了が先、完了済みが後
2. 締め切りが早い順。締め切りなしは最後
3. 同じ条件なら新しく作った順

## API

すべて要ログイン。未ログインは 401。

| メソッド | パス             | 内容                                           | 成功                 |
| -------- | ---------------- | ---------------------------------------------- | -------------------- |
| GET      | `/api/tasks`     | 自分のタスク一覧                               | 200                  |
| POST     | `/api/tasks`     | 作成。body: `{ title, dueAt? }`                | 201 (作成したタスク) |
| PATCH    | `/api/tasks/:id` | 完了状態の変更。body: `{ completed: boolean }` | 204                  |
| DELETE   | `/api/tasks/:id` | 削除                                           | 204                  |

- 他のユーザーのタスクを PATCH / DELETE しても何も変更されない (エラーにはならない)。
- JSON でない body は 400、未対応のメソッドは 405、未知のパスは 404。

タスクにファイルを添付できるようにする。以下は未決定。

- 添付できるファイルの種類、サイズ、数の上限

- タスク削除時の添付ファイルの扱い
- ダウンロード時の認可 (所有者だけが取得できること)

## 予定: 同時編集 (Durable Objects)

複数人が同じタスクを同時に編集できるようにする。現状はタスクが 1 人のユーザーに紐づくため、共有の仕組みから決める必要がある。以下は未決定。

- タスクの共有方法 (招待、権限)
- 同時編集の単位 (タスク単位かリスト単位か)
- 競合の解決方法
- WebSocket のメッセージ形式 (`CollaborationRoom` は接続を受け付けるだけの空の実装)
